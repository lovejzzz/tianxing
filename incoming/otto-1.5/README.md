## What the site must not name or sell

- Going home / 回家 is not sold. It is given: anyone who opens the game on 4 February 2027 or later gets it, once. From 31 January 2027 the store shows it, locked; before then the store does not show it at all. The in-game changelog names it, so it can be named. Don't give it a price or say it can be bought.
- Only the items above are in 1.5. Other liveries, sets and a second new Rush game were made while 1.5 was being built and left out; the site should name nothing that is not listed here.
- Christmas Gifts (from 1.4) is still given, not sold. In 1.5 its three liveries no longer appear on the store's All Ottos shelf before they are given.
